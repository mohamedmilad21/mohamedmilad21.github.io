# The PM Journal — Milad Elkilani

Personal site of Mohamed Milad Elkilani, Product Manager at Presto (Tripoli, Libya).

Live at <https://mohamedmilad21.github.io>

## Pages
- `index.html` — home: intro, skill tree, latest posts, how I work
- `work.html` — work history and timeline (the CV page)
- `journal.html` — journal index
- `posts/` — individual posts
- `style.css` — shared styles

## Adding a post
1. Copy any file in `posts/` as a starting point.
2. Update the `<title>`, `.kicker`, `<h1>`, `.dek` and `.byline`.
3. Add the post to the list in `journal.html`, and to the top of the list in `index.html`.
